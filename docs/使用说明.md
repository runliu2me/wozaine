# 使用说明

## 一、老人怎么用

教老人只需要一句话：**「想我了，就拍一下这个按钮，跟我说话。」**

- **拍一下**：设备先用你的声音打招呼（「妈，我在呢。今天怎么样？」），然后就可以直接说话，不用一直按着。
  她说完停一下，它就会回答；回答完会接着听。**30 秒没人说话**，这次聊天自动结束，设备回到待机。
- **聊到一半想打断**：再拍一下就行。
- **它主动找她**（需要打补丁的固件）：白天随机几次，设备会主动喊一声「妈，你在吗？」，她一应声，就会问她一个往事小问题。
- **没电了**：电量低于 20% 且没在充电时，它会说「妈，我快没电了，帮我接上充电线」，之后每 30 分钟最多提醒一次。
- **网络或服务出问题**：它会说「我这边网络有点不好，你等一会儿再拍一下按钮找我」，不会一声不吭；同时你会收到告警。

放设备的建议：放在老人每天坐得最多的地方（沙发边、餐桌上），插着充电线；离电视远一点，电视声音会被当成说话。
第一次给老人用时，你最好在旁边陪她聊一两次，或者用管理台的「对讲」远程陪她试。

## 二、管理台（手机浏览器打开你的域名）

建议把网址「添加到主屏幕」，像 App 一样用。

### 首页：一眼看
打开就是一块「表盘」，从上往下只回答三件事：

1. **有没有要你管的事。** 只有真有事才出现一条提醒，平时这里什么都没有：设备离线超过两小时（附上建议：打个电话请家里人看看设备亮不亮、路由器正不正常）、电量只剩两成且没在充电、服务连不上或语音接口出故障。
2. **设备在不在、电量多少。** 中间的圆环就是电量（绿 → 橙 → 红），圆里写着「在线 / 对话中 / 离线」，下面一句人话结论（「妈妈这边一切正常」「电量不多了，设备会提醒她充电」「现在联系不上妈妈那边」），再下面是连了多久、多久前有动静；离线时写「最后在线 3 小时前」。在充电时圆环外面会有一圈慢慢的呼吸。
3. **最近怎么样。** 「昨天」小卡片：昨天聊了几句，和近 7 天每天聊了多少的小柱子（一眼看出有没有哪天没聊）；「对讲」小卡片一点就进对讲。下面是最近一份日报：先给一句状态，有需要留意的事单独标出来，再列两三条「下回可以聊」的话题，全文收在「看全文」里。

顶栏左边永远是在线状态和电量；DeepSeek 余额只在偏低时才出现在顶栏（点一下进维护页）。

### 对讲
按住中间的圆，用你**自己真实的声音**直接跟她说（不经过 AI），松开就回到只听，她那边的声音会传过来。

- 先拨开「接通」：接通后只听，不会放出你的声音。
- 圆会跟着声音大小呼吸：她那边一出声、或者你按住说话时，你都能看见。右上角是接通了多久。
- 是半双工的：你说话时听不到她那边，松开就恢复（否则你的声音会从她的喇叭绕回来）。
- 电脑上可以按住空格键说话；手机上接通期间屏幕会尽量保持常亮；切到别的 App 时会自动松开，不会一直开着麦。
- 设备离线时这里会直接告诉你，不用白点。
- （接口 `/api/device/say` 还支持让设备用你的克隆声音说一句指定的话，页面上暂时没放按钮。）

### 记录
- 日历上颜色越深，那天聊得越多。默认打开最近一天有对话的日子；日历下面的 ‹ › 可以一天一天往前往后翻。
- 那天的**日报**在上面（同样先给一句结论），**原话**在下面：她说的在左，AI 用你的声音说的在右，和聊天软件一个习惯；隔了二十分钟以上算新的一场，中间有时间分隔线。
- 每一句都能点「播放」**回放原声**；被错字本改过的句子可以点「原识别」看识别原文。
- 没生成日报的日子可以点「生成日报」。今天的日报要等夜里整理完，第二天再看。

第一周建议每天看一遍记录：AI 哪句话说得不像你、她哪里没听懂，就去改人设（见下面「维护」）。

### 记忆
- **它记住的事**：每次聊完自动提炼的关于她的事实（家里人、习惯、最近的事），每晚自动整理去重。
  记错的直接改或删；也可以手动添加你希望它知道的事（比如「下周三去医院复查」）。
- **错字本**（只有管理员能看）：老人口音重，人名地名常被听错。在这里**确认一次正确写法和错写**，
  以后的对话入库前就会自动改对，以前的记录、记忆、日报、故事也会陆陆续续全部改过来。
  - 「直接改」：确认的错写，任何地方直接替换。
  - 「看上下文」：本身是个正常词（比如名字被听成「牛肉」），每晚交给 DeepSeek 逐处判断是不是听错。
  - 每一处修改都能撤销，识别原文永远保留。
  - 建议用一两周之后，翻翻记录里反复出现的奇怪的词，再来这里加。

### 故事
- **妈妈的故事**：AI 每次聊天会找时机问她一个往事小问题（「你小时候住在哪儿？那房子什么样子？」），
  每晚把她讲的**原话**摘出来，按人生章节整理成传记。
- **我想让 AI 问妈妈**：你和家人可以自己出题，或者指定「下次就问」哪一题。问过三次都没答的题会自动搁置。
- **传记 / 书**：每晚自动重写有变化的章节；书（`/book`）可以像真书一样翻页，每一段旁边都能看到她的原话、点开听录音。
  「复制全部」可以导出。

### 维护（只有管理员能看）
- **人设与说话风格**：直接编辑 `persona.md`，保存后下一句话就生效。这是最常改的地方。
- **余额**：DeepSeek 等账户余额，和语音识别的用量、费用估算。
- **连通性与服务**：检测各家接口是否正常；重启服务。
- **设备**：音量、重启设备、结束当前对话。
- **OTA 固件升级**：上传新编译的固件，设备下次开机自动升级。
- **接口与密钥**：改 `.env` 里的密钥、切换声音（保存后自动重启服务）。
- **测试对话 / 通话**：不用设备，直接在浏览器里和 AI 文字或语音聊几句，试人设效果。

### 家人账号
兄弟姐妹也想看？在服务器上执行：

```bash
venv/bin/python3 admin_password.py --user xiaohong --role family --name 小红
```

家人账号能看首页、记录和日报，能对讲、能给故事出题、能看和改「它记住的事」；看不到维护页、错字本和人设，也不能改密钥。首页的提醒对家人也是裁剪过的：设备离线、没电会照常提醒；欠费、接口故障这类服务问题只显示「已经通知管理员」。

## 三、日常维护

| 多久 | 做什么 |
|---|---|
| 第一周每天 | 看记录，调人设；看日报 |
| 每周 | 看一眼余额；翻翻故事；有反复听错的名字就加进错字本 |
| 每月 | 备份服务器上的 `data/` 目录（全部对话、录音、记忆、故事都在里面） |
| 收到告警时 | 离线：让家里人看看设备是不是没电、Wi-Fi 是不是断了；欠费：去对应平台充值 |

升级代码：在服务器的仓库目录里 `git pull && bash deploy/install.sh`。

## 四、费用大概多少

按一位老人每天聊 5～10 次、每次几分钟估算（以各家当前价格为准）：

| 项目 | 大约 |
|---|---|
| DeepSeek 对话 | 每月十几元以内 |
| 阿里云语音识别 | 每月十元左右 |
| MiniMax 语音合成 | 每月十几到几十元，取决于说话量；声音复刻有一次性费用 |
| 云服务器 | 2 核 4G，每月几十元起（有的厂商新用户一年一两百元） |
| 域名 | 每年几十元 |

设备硬件是一次性的，见 [硬件.md](硬件.md)。
