# 定制指南

## 1. 家庭档案 `family.json`

代码里不写死任何人名地名，全部从这里读（模板 `family.example.json`）：

| 字段 | 用在哪 | 例子 |
|---|---|---|
| `elder_name` | 故事书的署名和正文 | 王秀英 |
| `elder_brief` | 给模型的一句话背景（摘故事、出题、判错字） | 成都人，七十多岁，说四川话 |
| `elder_birth` | 写书 | 1950 年代 |
| `child_name` | AI 扮演的人；日报、故事里的称呼 | 小明 |
| `child_nickname` | 管理台里对 AI 的昵称 | 明明 |
| `child_role` | AI 扮演的角色（日报、故事提示词、书的副标题），默认「儿子」 | 儿子 / 女儿 / 孩子 |
| `elder_label` | 老人称呼（管理台、日报、故事提示词），默认「妈妈」 | 妈妈 / 爸爸 / 姥姥 |
| `elder_call` | 口头呼唤称呼（开场白、低电/兜底语音；不填按 `elder_label` 推导） | 妈 / 爸 / 姥姥 |
| `elder_pronoun` | 第三人称指代（不填自动推导） | 她 / 他 |
| `elder_city` / `child_city` | 每轮对话报时间天气（Open-Meteo，免费），名字 + 经纬度；同城就填一样的 | `{"name":"成都","lat":30.67,"lon":104.07}` |
| `book_title` | 故事书书名 | 妈，你慢慢说 |
| `asr_context` | 阿里云识别的提示词：说话人是谁、常说的人名 | 说话人是成都的老太太，儿子叫小明…… |
| `asr_hotwords` | 腾讯云识别热词 | 小明\|11,小红\|10 |
| `timezone_offset_hours` | 时区 | 8 |

改完重跑 `bash deploy/install.sh`（或 `sudo /usr/local/sbin/wozaine-restart xiaozhi-bridge.service companion.service`）。

## 2. 人设 `persona.md`

这是效果好坏的关键。模板 `persona.example.md` 里的「说话方式」「让她越聊越开心」等规则是在真实老人身上反复调出来的，建议保留。
你主要补三类东西：

1. **你是谁**：经历、工作、忙不忙。老人问起来它要答得上。
2. **家里的事实**：谁叫什么、住哪儿、多久回去一次、家里有没有保姆。写错一个事实，它就会一本正经地说错话。
3. **老人的情况**：身体、记忆、作息、口音。告诉它「怎么应对」，同时叮嘱它**不要说破**。

调法：看一周「记录」，把不像你的回答挑出来，在人设里加一条正面例子和反面例子——模型对「要这样说 / 不要这样说」的例子最敏感。
人设在管理台「维护」里就能改，保存即生效。

## 3. 故事题库 `story_seed.json`

第一次运行时写进 `data/story/questions.json`，之后在管理台「故事」页加题、改题。
想按老人的经历调整（比如她当过兵、下过乡、在国外生活过），改章节名和问题即可；
原则：**一个问题只问一件具体的小事，大白话，给她一个容易接的钩子**（「你小时候睡的床是木头的还是竹子的？」）。
每晚 AI 还会根据她讲过的事自动出几道「只有她能答」的追问题。

## 4. 错字本第一批词 `typo_seed.json`（可选）

格式见 `typo_seed.example.json`。不知道哪些词会被听错的话不用填，跑一两周后在管理台里加更准。

## 5. 陪爸爸，或者别的家人

不需要改 Python 源码，只需改两处配置：

1. **`family.json`**：把 `elder_label` 改成 `"爸爸"`（或 `"姥姥"` / `"爷爷"` 等），`elder_call` 改成 `"爸"`（可省略，会自动从 `elder_label` 推导），`elder_pronoun` 改成 `"他"`（也可省略自动推导），`child_role` 改成 `"儿子"` / `"女儿"` / `"孩子"`，`book_title` 改成你想要的书名。
   - 设备的开场白、主动问候、低电量提示、网络兜底语音，以及管理台标签、日报/记忆/故事/写书/错字本提示词都会自动切换。
   - 如想自定义开场白或兜底话术，也可在 `family.json` 里选填 `greetings`、`proactive_greetings`、`low_battery_text`、`fallback_text`。
2. **`persona.md`**：全文把「妈妈 / 妈 / 她」换成对应的称呼与人称，写清楚家里真实情况。

改完后重启服务即可生效（Linux 执行 `sudo /usr/local/sbin/wozaine-restart xiaozhi-bridge.service companion.service`）。

## 6. 让它知道你的行程

`.env` 里填 `SCHEDULE_ICS_URL`（飞书 / 钉钉 / Google / Outlook / iCloud 日历都能导出私密的 iCal 订阅链接），
重跑安装脚本后每小时同步一次。老人问「你最近忙什么」「哪天回来」，它就照日历说，不编。
也可以手写 `data/schedule.json`，格式见 `sync_schedule.py` 开头。

## 7. 告警

`device_monitor.py` 支持企业微信 / 飞书 / 钉钉群机器人 webhook（`ALERT_WEBHOOK_URL` + `ALERT_WEBHOOK_KIND`），
或者任意命令（`ALERT_COMMAND`，告警文字从标准输入传进去）。想接别的渠道，改 `notify()` 函数即可。

## 8. 电话线路（进阶，可选）

老人打你的手机你没接时，可以让云厂商的「语音智能体 / 智能联络中心」接起来，用同一个人设、同一份记忆陪她说话。
本项目提供 OpenAI 兼容的 `POST https://你的域名/v1/chat/completions`（`phone_brain.py`），
鉴权 `Authorization: Bearer <PHONE_API_KEY>`，支持流式。在云厂商控制台把「大模型」配置成这个地址即可，
通话内容会以 `[电话]` 前缀记进管理台的记录。具体接线方式以各家文档为准。

## 9. 换模型或服务商

- **对话模型**：`deepseek_client.py` 用的是 OpenAI 兼容的 Chat Completions 格式，`DEEPSEEK_API_URL` / `DEEPSEEK_MODEL`
  可以指向其他兼容服务（智谱 GLM、通义千问、Kimi、本地 vLLM 等）；如果目标模型默认开启思考模式导致语音回复慢，可配 `DEEPSEEK_EXTRA_BODY` 透传额外参数。更换为非 DeepSeek 官方地址后，管理台余额页和 `device_monitor.py` 会自动跳过 DeepSeek 官方余额查询，不会报 401。注意错字本判断默认用 `deepseek-chat`（`TYPO_JUDGE_MODEL`）和 `deepseek-reasoner`（`TYPO_AUTO_JUDGE_MODEL`），换服务商后若启用错字本请一并改掉。

  示例（以智谱 GLM 兼容接口为例，请替换成自己的地址与密钥）：
  ```ini
  DEEPSEEK_API_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
  DEEPSEEK_API_KEY=你的密钥
  DEEPSEEK_MODEL=glm-4.7
  DEEPSEEK_EXTRA_BODY='{"thinking":{"type":"disabled"}}'
  ```

- **语音识别**：`asr_client.py`，接口是 `transcribe_pcm(16k/16bit/单声道 PCM) -> 文字`，加一家照着写一个函数。如果只配腾讯云、不配阿里云，把 `DASHSCOPE_API_KEY` 留空即可直接走腾讯云，不会误记阿里云失败或发降级告警。
- **语音合成**：`tts_client.py`，接口是 `synthesize(text) -> mp3 bytes`。MiniMax 因账号所属站点不同，若默认地址报 `invalid api key`，可在 `.env` 里改 `MINIMAX_API_URL=https://api.minimaxi.com/v1/t2a_v2`；新版 API Key 下 `MINIMAX_GROUP_ID` 可留空。
