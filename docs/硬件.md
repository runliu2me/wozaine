# 需要什么硬件

一共三样：**老人身边的小盒子**、**一台云服务器**、**一个域名**。另外要一台电脑刷一次固件（或烧我们编好的 ROM）。

## 1. 老人身边的小盒子（设备）

设备端跑的是开源的[小智 AI 固件（xiaozhi-esp32）](https://github.com/78/xiaozhi-esp32) + 本仓库的陪聊补丁。

### 我们用的是哪块板（不是推荐）

我们家里那台、以及本仓库的 **firmware 补丁和预编译 ROM**，都是基于 **征辰 Minicam**（板型 `zhengchen-minicam`，ESP32-S3 N16R8，带屏、双麦）做的。这块板上焊着一个摄像头接口，但**我们的固件补丁不初始化摄像头，也没有任何拍照功能**——「我在呢」只用声音陪伴。

> [!IMPORTANT]
> **我们不推荐你一定要买这块板。** 只是实话告诉你：我们的固件和 ROM 是基于它的，所以 Minicam 用户可以最省事——直接烧 Release 里的 `merged-binary.bin`，或按默认配置自己编译。
> 如果你手里是别的 ESP32-S3 小智板，完全可以继续用：把补丁打上去，改一下板型配置；或者把 `firmware/` 目录交给 AI，让它按你的板子改一改（见 [firmware/README.md](../firmware/README.md)「换别的板子」）。

Minicam 大致规格（方便对照，不是购物清单）：

| 项目 | 规格 |
|---|---|
| 主控 | ESP32-S3 N16R8（16MB Flash + 8MB PSRAM） |
| 音频 | ES8311 + 双麦克风，支持设备端回声消除（对讲需要） |
| 屏幕 | 约 320×240 LCD |
| 摄像头 | 板上有接口，**本项目不启用**（固件不初始化、没有拍照功能） |
| 按键 | 拍一下开始对话、再拍一下结束；另有音量键 |

> [!TIP]
> 有些便宜的板子 Type-C 口缺 CC 电阻，用「C 对 C」线接电脑可能识别不出来。刷固件时用 **USB-A 转 Type-C** 的线最稳。

### 换别的板子要有什么

| 想要的功能 | 板子要有 |
|---|---|
| 基本聊天 | ESP32-S3（建议 8MB PSRAM）、麦克风、喇叭（**不需要摄像头**，选没有摄像头的板子更省心） |
| 对讲（手机和老人直接说话） | 支持设备端回声消除（AEC）的音频方案，否则会有回声 |
| 没电提醒 | 电池电量检测 |
| 一拍就聊 | 有一个容易按到的按键；补丁提供 `StartConversation()` / `StopConversation()`，按键回调里调一下即可 |

不打补丁、直接用上游官方固件也能聊天，只是没有对讲、主动问候、自愈重启等功能，对照表见 [firmware/README.md](../firmware/README.md)。
ESP32-C3/C6 等内存小的芯片没验证过，不建议。

### 外壳和摆放

- 开发板裸板不适合直接给老人用：做一个外壳，把**按钮做大、做显眼**（我们的经验是一个红色的大按钮），喇叭开孔朝向老人。
  3D 打印最方便；`hardware/enclosure.scad` 是我们早期给另一块板子（微雪 ESP32-S3-AUDIO-Board）画的大按钮外壳（OpenSCAD），可以参考改尺寸。
- 一直插着充电线放在固定位置，比靠电池移动着用可靠得多。
- 远离电视和音箱，电视声音会被当成说话。

### 刷固件要准备

- 一台电脑（Windows / macOS / Linux 都行）。Minicam 用户可以只装 esptool，烧 Release 里的整包；自己编译要装 ESP-IDF v6.0.x。
- 一根能传数据的 USB 线（见上面的提示）。
- 步骤见 [firmware/README.md](../firmware/README.md)。

## 2. 云服务器

| 项目 | 建议 |
|---|---|
| 配置 | 2 核 4G 内存、20GB 以上硬盘（录音每月几百 MB） |
| 系统 | Ubuntu 22.04 / 24.04 或 Debian 12 |
| 网络 | 公网 IP，安全组放行 80、443 |
| 地域 | 离老人近、到国内各家 AI 接口快的地方。**中国大陆的服务器要求域名 ICP 备案**才能对外提供 80/443 网页服务；没有备案的域名就选香港或海外服务器 |

不需要 GPU：语音识别、对话、合成都调用云接口；本地只跑一个很小的语音活动检测模型（Silero VAD，ONNX，CPU 即可）。

家里有一直开着的电脑或 NAS 也可以当服务器，但需要能被设备从公网访问到（内网穿透 + 域名 + HTTPS），稳定性要自己保证——
老人那边一旦连不上，就是「拍了没反应」。

## 3. 域名

一个能加 DNS 解析记录的域名（任何注册商都行），用一个子域名指向服务器，比如 `chat.example.com`。
安装脚本会自动申请免费的 HTTPS 证书（Let's Encrypt）。设备只认 HTTPS / WSS。
