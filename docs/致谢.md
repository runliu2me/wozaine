# 致谢与致敬

「我在呢」能开口、能记住、能写成书，靠的是许多人已经铺好的路。完整人话版在部署后的 **`/thanks`（致敬）** 页；登录页页脚、管理台顶栏、首页最下面和维护页最下面都留了入口，未登录也能看。

## 开源

- [78/xiaozhi-esp32](https://github.com/78/xiaozhi-esp32)（MIT）——设备端根基
- [Silero VAD](https://github.com/snakers4/silero-vad)（MIT）——语音活动检测
- [StPageFlip](https://github.com/Nodlik/StPageFlip)（MIT）——故事书翻页
- [78/esp-ml307](https://github.com/78/esp-ml307)（Apache-2.0）——设备网络组件，我们加了连接/发送超时
- [shadcn/ui](https://github.com/shadcn-ui/ui)（MIT）——管理台的 neutral 色板与尺寸

## 思路

- [StoryWorth](https://www.storyworth.com/)——「每次只问一个往事问题，攒成一本书」
- 智能手表的表盘——管理台首页「一眼可读、没事安静、有事清楚」的排法

## 硬件与工具链

- 征辰 Minicam：我们家里实际在用的板（补丁/ROM 基于它；不是购物推荐；板上摄像头不启用）
- Espressif ESP-IDF（Apache-2.0）：编译与烧录

## 云能力与运行时

DeepSeek、阿里云/腾讯云语音识别、MiniMax / CosyVoice；以及 Python 依赖、FFmpeg、nginx、systemd、certbot。
